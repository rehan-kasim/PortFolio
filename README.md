## Getting Started
### Dependencies
* A modern Browser
* VS Code optional
* Python Optional

* Download the Github Repo As Zip
* Do ```git clone https://github.com/rehan-kasim/portfolio```
### Executing Program
* Download the file and double click it to open this in browser
* Or launch a python Local Server
* Or Use live Server Extension In VS Code
